# M Personal Training

A mobile-first fitness app UI built with React, Vite, and Tailwind CSS. Includes a home dashboard, guided workout sessions with rest timers and PR detection, nutrition/macro tracking, progress charts, and an AI coach chat panel — all backed by a mock data layer that can be swapped for a real API later.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint

## Stack

- React 19 + Vite
- Tailwind CSS 4
- [lucide-react](https://lucide.dev/) for icons
- [Recharts](https://recharts.org/) for progress charts
